# Mechanical reference

The recovered reference envelope is **92.710 x 63.500 mm**. The working coordinates use the lower-left envelope as origin, X right and Y up.

Three mounting-hole centers are (14.478, 4.826), (89.916, 11.557), and (51.435, 60.706) mm, nominal diameter 3.2512 mm. Tiny drafting gaps were joined and arcs approximated; maximum shared-feature discrepancy after the recorded repair is 0.016510 mm.

The internal PCB slot is absent from the bottom enclosure drawing. It is retained from the GM1 PCB reference. Enclosure thickness, component heights, tool clearances and physical fit still need validation. This is not a finished enclosure or manufacturing release.
